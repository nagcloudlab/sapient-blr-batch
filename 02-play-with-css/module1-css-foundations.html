Module 1: CSS Foundations

3 Ways to Add CSS

1. Inline CSS — Written directly on the element using the style attribute. (Highest priority, but hard to maintain)

2. Internal CSS — Written in a <style> tag inside <head>. (Good for single-page demos)

3. External CSS — Written in a separate .css file, linked with <link>. (Best practice for real projects)

Basic Selectors

Element selector: This paragraph is styled by the p selector.

Class selector (.highlight): This has a yellow background.

ID selector (#main-title): The title above uses an ID selector.

Universal selector (*): The * selector applies box-sizing to everything.

Colors

RGB Color: color: rgb(46, 204, 113);

RGBA Color (with transparency): background: rgba(52, 152, 219, 0.3);

HSL Color: color: hsl(280, 60%, 50%);
