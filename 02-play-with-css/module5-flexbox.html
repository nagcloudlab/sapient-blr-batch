27. Flex Items (grow, shrink, basis)

flex-grow — how items share extra space

grow: 0
grow: 1
grow: 2

Item with grow:2 gets twice the extra space as grow:1. grow:0 stays at content size.

flex-shrink — how items shrink when space is tight

shrink: 0
shrink: 1
shrink: 3

shrink:0 won't shrink. shrink:3 shrinks 3x faster than shrink:1.

flex-basis — starting size before grow/shrink

basis: 100px
basis: 200px
basis: auto

Shorthand: flex: grow shrink basis

flex: none
flex: auto
flex: 1

flex: 1 = flex: 1 1 0% (most common — equal sizing)

29. order

HTML order: 1(red), 2(blue), 3(green) — but CSS reorders them:

HTML: 1st, order: 3
HTML: 2nd, order: 1
HTML: 3rd, order: 2

Visual order: green(1) → blue(2) → red(3). Default order is 0.

Bonus: Perfect Centering

justify-content: center + align-items: center = Perfectly Centered!

The most popular use of flexbox — centering anything with just 3 lines of CSS.
