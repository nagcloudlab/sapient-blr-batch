Animation Properties Cheat Sheet

Property Values Description
animation-name @keyframes name Which animation to use
animation-duration 0.5s, 2s, 300ms How long one cycle takes
animation-timing-function ease, linear, ease-in-out Speed curve
animation-delay 0s, 0.5s, 1s Wait before starting
animation-iteration-count 1, 3, infinite How many times to play
animation-direction normal, reverse, alternate Play direction
animation-fill-mode none, forwards, backwards, both Style before/after animation
animation-play-state running, paused Pause/resume

45. Performance

GOOD (GPU-accelerated, no layout recalc):
transform (translate, rotate, scale) and opacity
AVOID animating (triggers layout/repaint):
width, height, margin, padding, top, left, font-size

Rule of thumb: Animate transform and opacity. Use transform: translateX() instead of left. Use transform: scale() instead of width/height.
