Module 2: The Box Model

7. Box Model Concept

Every HTML element is a rectangular box with 4 layers:

  +------------ MARGIN (outside spacing) -----------+
  |  +---------- BORDER (visible edge) ----------+  |
  |  |  +------- PADDING (inside spacing) -----+ |  |
  |  |  |                                       | |  |
  |  |  |        CONTENT (text/image)           | |  |
  |  |  |                                       | |  |
  |  |  +---------------------------------------+ |  |
  |  +---------------------------------------------+  |
  +-------------------------------------------------+
I have padding, border, and margin!

Inspect this box in DevTools (F12) to see the box model diagram.

8. box-sizing: border-box

content-box (default): width:300px + padding:40px + border:10px = 350px total!
border-box: width:300px = 300px total! (padding & border fit inside)

Best practice: Always use *, *::before, *::after { box-sizing: border-box; }

9. Margin Collapsing

margin-bottom: 40px
margin-top: 25px

The gap between boxes = 40px (NOT 65px). The larger margin wins — this is margin collapsing.

Only happens vertically, not horizontally. Does NOT happen with flexbox or grid.
