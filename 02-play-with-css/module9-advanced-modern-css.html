46. CSS Variables (Custom Properties)

Declaring & Using Variables

:root {
    --primary: #3498db;       /* Declare on :root for global */
    --spacing: 20px;
}

.card {
    color: var(--primary);    /* Use with var() */
    padding: var(--spacing);
    margin: var(--spacing, 10px);  /* Fallback value */
}

52. CSS Nesting (Modern Browsers)

/* Before (flat) */
.card { ... }
.card h4 { ... }
.card p { ... }
.card:hover { ... }

/* After (nested) */
.card {
    & h4 { color: blue; }
    & p { color: gray; }
    &:hover { border-color: blue; }
    & .tag {
        &:hover { opacity: 0.8; }
    }
}
