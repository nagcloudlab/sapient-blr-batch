# Module 13: QE/QC Testing -- FoodExpress Quality Assessment

## Sustain Context

The client escalated:

> "We have had 23 production bugs in the last month, 8 of which were regressions. Our test coverage is below 30%, we have no test strategy document, and bugs are being triaged ad-hoc with no clear priority framework. We need the sustain team to establish a quality baseline: write test cases for the critical order flow, triage the current bug backlog, create a test strategy for the next release, and decide which tests to automate first. Plus the team needs to practice quality communication through role play."

---

## Tasks

| # | Type | Task | Deliverable |
|---|------|------|-------------|
| 1 | EXERCISE | Write 15 test cases for Order Placement feature | Test case table with steps and expected results |
| 2 | EXERCISE | Triage 8 production bugs -- classify and select 4 to fix | Prioritized bug table with justification |
| 3 | EXERCISE | Create test strategy document for FoodExpress v2.4 release | 1-page test strategy covering scope, types, criteria |
| 4 | EXERCISE | Build automation decision matrix for 200 test cases | Scored matrix showing which 80 to automate first |
| 5 | MCQ | Complete QE/QC knowledge assessment | MCQ score |
| 6 | ROLE PLAY | Round 1: Test plan for loyalty rewards feature | Team presentation of test plan and test cases |
| 7 | ROLE PLAY | Round 2: Production bug triage simulation | Team presentation of prioritization decisions |

## Deliverables

- [ ] 15 test cases covering positive, negative, boundary, and edge cases
- [ ] Bug triage table with severity, priority, and fix decisions
- [ ] Test strategy document (scope, types, entry/exit criteria, risks)
- [ ] Automation decision matrix with scoring and justification
- [ ] MCQ assessment completed
- [ ] Active participation in both role play rounds
