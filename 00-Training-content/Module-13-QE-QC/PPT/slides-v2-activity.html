MODULE 13MINDSET
Quality Principles for Sustain Engineers
  • Prevention over detection -- catch defects early, not in production
  • Shift left -- test at requirements, design, code, not just at the end
  • Everyone owns quality -- not just the QA team
  • Every bug fix gets a test -- so it never comes back
  • Ask "How was this missed?" -- improve the process, not just the code
You are sustain engineers. You inherit code with technical debt. Your job is to make it better, not perfect. Start with the highest-risk areas.
