# SRE Automation -- Project Brief
## Module 33 | Days 37-38

---

## Sustain Context

FoodExpress is formalizing its SRE practices. The team needs to define SLIs/SLOs, establish error budgets, reduce toil, and build an incident response framework. As a sustain engineer, you will set up the SRE foundation that enables the team to balance reliability with feature velocity.
