# Module 16: Confluence & Jira -- FoodExpress Agile Tooling

## Sustain Context

The client escalated:

> "Our sustain team is not using Jira and Confluence effectively. Issues are created without proper descriptions, bugs are missing reproduction steps, JQL filters are not set up for dashboards, runbooks are outdated or missing, and sprint ceremonies are inconsistent. We need every engineer to be fluent in Jira issue management, JQL querying, Confluence documentation, and Agile ceremonies. Complete the exercises and participate in the SDLC role play."

---

## Tasks

| # | Type | Task | Deliverable |
|---|------|------|-------------|
| 1 | EXERCISE | Create 6 Jira issues (epic, story, bugs, task, sub-task) with all required fields | Written issues in proper Jira format |
| 2 | EXERCISE | Write 12 JQL queries for common sustain scenarios | JQL query table |
| 3 | EXERCISE | Write Confluence runbook, RCA, and release notes | 3 Confluence documents |
| 4 | EXERCISE | Design Kanban board with columns, WIP limits, swimlanes | Board design document |
| 5 | ROLE PLAY | Phase 1: Sprint planning -- select stories from backlog | Sprint backlog with goal |
| 6 | ROLE PLAY | Phase 2: Sprint execution -- standup, new bug, blocker resolution | Updated board, new bug report |
| 7 | ROLE PLAY | Phase 3: Sprint review + retro -- demo, velocity, action items | Review notes + retro document |

## Deliverables

- [ ] 6 Jira issues with complete fields (summary, description, acceptance criteria, priority)
- [ ] 12 JQL queries covering common sustain scenarios
- [ ] Runbook with prerequisites, steps, verification, and escalation
- [ ] RCA with timeline, root cause, contributing factors, and action items
- [ ] Release notes for v2.4 with features, fixes, and known issues
- [ ] Kanban board design with justified WIP limits
- [ ] Active participation in all 3 phases of SDLC role play
