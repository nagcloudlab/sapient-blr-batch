# Module 16 Checklist -- Participant Submission

## Jira Issue Creation
- [ ] Epic created with business justification
- [ ] User story with 3 acceptance criteria in Given/When/Then format
- [ ] Bug report with numbered steps to reproduce, expected vs actual, environment
- [ ] Task with specific requirements and acceptance criteria
- [ ] Sub-task linked to parent story with technical specs
- [ ] Bug with issue links (Relates to, Blocks)

## JQL Queries
- [ ] All 12 JQL queries written and syntactically correct
- [ ] Queries use appropriate operators (=, !=, in, ~, >=, is EMPTY)
- [ ] Queries use dynamic functions (currentUser(), openSprints(), now())
- [ ] Dashboard design with 4 gadgets and their JQL queries

## Confluence Documentation
- [ ] Runbook includes: overview, prerequisites, steps, verification, rollback, escalation
- [ ] Runbook includes exact commands (not vague instructions)
- [ ] RCA includes: summary table, timeline, root cause, contributing factors
- [ ] RCA includes action items with owner and due date
- [ ] Release notes include: features, bug fixes, known issues

## Board Design
- [ ] At least 5 columns defined for Kanban board
- [ ] WIP limits set with justification for each column
- [ ] Swimlanes defined
- [ ] Card colors defined by issue type
- [ ] Quick filters defined with JQL

## SDLC Role Play
- [ ] Phase 1: Sprint planning completed, items selected within velocity
- [ ] Phase 1: Sprint goal defined as a clear sentence
- [ ] Phase 2: Standup completed, blocker addressed
- [ ] Phase 2: New bug FOOD-182 created in proper format
- [ ] Phase 3: Sprint review completed, velocity calculated
- [ ] Phase 3: Retrospective with "went well", "improve", and action items

## Self-Check Questions
1. What are the 5 standard Jira issue types and when do you use each?
2. How do you write a JQL query to find all bugs assigned to you that are overdue?
3. What is the difference between a Scrum board and a Kanban board in Jira?
4. What are WIP limits and why are they important?
5. What sections should every runbook include?
6. What is the purpose of a Root Cause Analysis document?
7. How do Jira and Confluence integrate with each other?
8. What are the four Scrum ceremonies and what is the purpose of each?
9. What makes a good sprint goal?
10. How do you calculate team velocity?
