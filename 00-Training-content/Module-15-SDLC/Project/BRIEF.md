# Module 15: SDLC Fundamentals -- FoodExpress Development Process

## Sustain Context

The client escalated:

> "Our new sustain team members do not understand our development process. They are skipping environments, deploying untested code, writing user stories without acceptance criteria, and not following change management. We need everyone aligned on SDLC stages, the correct methodology for each type of work, how our environment pipeline works, and how changes should be managed. Complete these exercises to build that foundation."

---

## Tasks

| # | Type | Task | Deliverable |
|---|------|------|-------------|
| 1 | EXERCISE | Write 5 user stories + SRS excerpt + RTM for Scheduled Orders | Requirement documentation |
| 2 | EXERCISE | Select SDLC methodology for 6 FoodExpress projects | Methodology recommendation table |
| 3 | EXERCISE | Design 5-environment pipeline for FoodExpress | Environment strategy document |
| 4 | EXERCISE | Apply STLC stages to FoodExpress v2.4 release | Test plan + test cases + test summary |
| 5 | EXERCISE | Complete change management simulation for FOOD-156 | Change request form + risk assessment |

- [ ] 5 user stories with acceptance criteria in Given/When/Then format
- [ ] SRS excerpt with input, process, output, and error cases
- [ ] Methodology recommendations with justification for all 6 projects
- [ ] Environment pipeline with data sources, deployment methods, and monitoring
