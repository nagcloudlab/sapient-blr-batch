# Module 15 Checklist -- Participant Submission

## Requirements Documentation
- [ ] 5 user stories written with As/I want/So that format
- [ ] Each story has at least 2 acceptance criteria in Given/When/Then format
- [ ] SRS excerpt includes: Input, Process, Output, Error Cases
- [ ] At least 3 error cases defined with HTTP status codes
- [ ] Non-functional requirements specified (performance, reliability)
- [ ] Requirements Traceability Matrix created

## Methodology Selection
- [ ] All 6 projects have a methodology recommendation
- [ ] Each recommendation includes justification
- [ ] At least 3 different methodologies used across the 6 projects
- [ ] Risk of wrong methodology identified for at least 2 projects

## Environment Strategy
- [ ] 5 environments defined (Local, Dev, Staging, Pre-Prod, Prod)
- [ ] Each environment has purpose, users, data source, deploy method
- [ ] Environment variables table completed for all environments
- [ ] 3 code promotion rules defined

## STLC Application
- [ ] 5 testable requirements identified
- [ ] Test plan with scope, types, entry/exit criteria defined
- [ ] 10 test cases written (5 per feature)
- [ ] Test summary with realistic metrics

## Change Management
- [ ] Change request form fully completed
- [ ] Change type correctly classified
- [ ] Rollback plan specified
- [ ] 3 deployment risks identified with mitigations

## Self-Check Questions
1. What are the 7 stages of SDLC?
2. When should you use Waterfall vs Scrum vs Kanban?
3. What is the difference between BRD, SRS, and FRD?
4. What are the STLC stages and how do they relate to SDLC?
5. Why do we need multiple environments (Dev, Staging, Prod)?
6. What is the difference between Standard, Normal, and Emergency changes?
7. What are the four DORA metrics and what do they measure?
8. What does a user story's acceptance criteria define?
