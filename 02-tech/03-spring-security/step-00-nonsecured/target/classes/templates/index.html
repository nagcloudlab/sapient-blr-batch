WARNING: This application has NO SECURITY applied. Any user can access any page. Passwords are stored in plain text. There is no authentication or authorization.

Application Features

All Events — Shows all events for all users. Should be admin-only. My Events — Hardcoded to user1@example.com. No login required! Create Event — Anyone can create events as user1@example.com. H2 Database Console — Full database access! JDBC URL: jdbc:h2:mem:calendardb, user: sa, no password.
Security Vulnerabilities in This App
  1. No Authentication — Anyone can access any page without logging in
  2. No Authorization — No role-based access control (admin pages open to all)
  3. Plain-text Passwords — Passwords stored as-is in the database
  4. Hardcoded User — Always acts as user1@example.com (UserContextStub)
  5. No CSRF Protection — Forms can be submitted from any origin
  6. Database Console Exposed — H2 console gives full DB access to anyone
  7. No Session Management — No session fixation protection
  8. No Security Headers — Missing X-Frame-Options, CSP, etc.
