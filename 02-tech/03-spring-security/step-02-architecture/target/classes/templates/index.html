Step 02: Architecture — Debug logging is enabled. Check the console to see every security filter that processes each request. A SecurityFilterLogger bean prints all registered filters at startup.

What Changed in This Step

  1. Debug logging — logging.level.org.springframework.security=DEBUG in application.properties
  2. SecurityFilterLogger — A bean that prints all filters in the chain at startup
  3. No security behavior changed — This step is about understanding, not changing

Try This

  1. Look at the startup console → see the SPRING SECURITY FILTER CHAIN listing
  2. Make a request → watch the DEBUG log show each filter processing the request
  3. Count the filters — there are 15+ filters for every single HTTP request!
  4. Open the presentation.html to understand what each filter does
