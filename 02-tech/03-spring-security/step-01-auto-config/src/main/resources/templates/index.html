Step 01: Spring Security is now active! You had to log in to see this page. The only change was adding spring-boot-starter-security to pom.xml.

What Spring Security Auto-Configured

  1. All endpoints secured — Every URL now requires authentication
  2. Default login page — Spring generated /login for you
  3. Default user — Username: user, Password: check the console log
  4. Logout — /logout endpoint is available
  5. CSRF protection — POST requests require a CSRF token
  6. Session management — Session fixation protection enabled
  7. Security headers — X-Frame-Options, X-Content-Type-Options added
  8. H2 Console blocked — Frame-based console blocked by X-Frame-Options

Application Features

All Events — Now requires authentication to access My Events — Still hardcoded to user1@example.com (we'll fix later) Create Event — CSRF token is now auto-added by Thymeleaf
Try This
  1. Open an incognito window → go to http://localhost:8080 → redirected to /login
  2. Check the console for: Using generated security password: xxxxxxxx
  3. Login with user / <generated-password>
  4. Visit /logout to sign out
  5. View page source → notice the hidden _csrf field in forms
  6. Open DevTools → Network tab → check response headers for security headers
