17. Specificity Rules

Selector Specificity Score
pElement(0, 0, 0, 1)
.highlightClass(0, 0, 1, 0)
p.highlightElement + Class(0, 0, 1, 1)
#headerID(0, 1, 0, 0)

I'm green (class wins over element)

Rule: Inline > ID > Class/Attribute/Pseudo-class > Element/Pseudo-element
