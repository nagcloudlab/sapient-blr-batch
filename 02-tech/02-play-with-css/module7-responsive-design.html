36. Viewport Meta Tag

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Without it: Mobile browsers render at ~980px and zoom out (tiny text).
With it: Page width matches device width. Text is readable.

37. Relative Units

px: 16px — fixed, doesn't scale
em (parent: 20px): 1.5em = 30px
rem: 1.5rem = 24px (root is 16px)
%: relative to parent
Parent: 100%
Child: 50%
vw: viewport width
50vw = half the viewport
vh: viewport height
20vh = 20% of viewport height
UnitRelative ToBest For

40. Responsive Images

max-width: 100% (scales down, never up)

Image scales to fit container but never exceeds its natural size.

object-fit: cover (for fixed-size containers)

object-fit: cover fills the container and crops excess. Great for image grids!
