This text wraps around the floated elements. Float was originally designed for text wrapping around images, like in newspapers. Before Flexbox and Grid, developers used floats for entire page layouts. Today, we use Flexbox and Grid instead.

23. Overflow

visible (default)
Content spills out of the box when it's too long. This is the default behavior. Extra text keeps going beyond the boundary.
hidden
Content is clipped. You can't see what's beyond the box. The extra content is simply cut off.
scroll
Always shows scrollbars, even if content fits. This ensures consistent scrollbar appearance.
auto
Scrollbars only appear when content overflows. This is the most common choice. Smart and clean.
