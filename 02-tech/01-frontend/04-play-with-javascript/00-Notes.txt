


javascript language features
------------------------------

-> single-threaded processing model ( lightweight )
-> non-blocking I/O operations ( asynchronous )
-> event-driven programming model

-> first-class functions ( functions are treated as objects )
-> object-oriented programming ( supports classes and prototypes )
-> dynamic typing ( variables can hold any type of data )

javascript follows ECMAScript standard,
which defines the syntax and features of the language. 

current version => ECMAScript is ES2021 (ECMAScript 12)

complexities while plain-javascript( your code) with browser APIs
-------------------------------------------------------------

-> browser compatibility issues (different browsers may implement APIs differently)
-> performance issues (plain JavaScript may not be optimized for performance)
-> memory management issues (plain JavaScript may not handle memory efficiently)
-> too much boilerplate code (writing repetitive code for common tasks)
-> code reusability issues (plain JavaScript may not provide a way to reuse code effectively)
.....



legacy solutions to overcome these complexities
-------------------------------------------------------------

-> server-side rendering (SSR) (rendering HTML on the server and sending it to the client)

    - jsp ( Java Server Pages )
    - php ( Hypertext Preprocessor )
    -> asp.net ( Active Server Pages )
    -> ruby on rails ( web application framework written in Ruby )

modern solutions to overcome these complexities
-------------------------------------------------------------

-> client-side rendering (CSR) (rendering HTML on the client using JavaScript)
`
-> modern browser APIs (newer APIs that provide better performance and functionality)
-> modern JavaScript frameworks and libraries (tools that provide a structured way to build web applications)
