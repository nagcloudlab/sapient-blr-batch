


REST ( Representational State Transfer) 
--------------------------------------


steps to design a REST API
-----------------------------

step 1: Identify the resources

        /api/v1/todos
        /api/v1/todos/{todoId}
        /api/v1/users
        /api/v1/users/{userId}
        /api/v1/users/{userId}/todos

step 2: Identify the HTTP methods ( actions) for each resource

        read
        -----

        GET /api/v1/todos
        HEAD /api/v1/todos
        OPTIONS /api/v1/todos

        write
        ------

        POST /api/v1/todos
        PUT /api/v1/todos/{todoId}
        PATCH /api/v1/todos/{todoId}
        DELETE /api/v1/todos/{todoId}
        
step 3: Resource representation ( JSON, XML, HTML, etc)

        JSON
        ----
        {
            "id": 1,
            "title": "Learn Spring Boot",
            "description": "Learn Spring Boot in 30 days",
            "completed": false
        }

        XML
        ---
        <todo>
            <id>1</id>
            <title>Learn Spring Boot</title>
            <description>Learn Spring Boot in 30 days</description>
            <completed>false</completed>
        </todo>

step 4: Identify the response status codes

        200 OK
        201 Created
        204 No Content
        400 Bad Request
        401 Unauthorized
        403 Forbidden
        404 Not Found
        500 Internal Server Error
