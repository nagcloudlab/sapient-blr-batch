


IO sources
--------------

- standard input ( keyboard ) | standard output ( screen ) | stdout
- file input | file output
- buffered input | buffered output
- network sockets



IO streams
--------------

java.io package provides two types of streams:

- byte streams (InputStream, OutputStream) => used for reading and writing binary data
- character streams (Reader, Writer) => used for reading and writing text data



IO streams can be classified into two categories:
-------------------------------------------------

1. Input streams: used for reading data from a source (e.g., file, keyboard, network)
2. Output streams: used for writing data to a destination (e.g., file, console, network)




IO Classes
-----------------

- InputStreamReader 
  - It is a bridge from byte streams to character streams: It reads bytes and decodes them into characters using a specified charset.
  - It is used to read data from an InputStream (like System.in) and convert it into characters.

- BufferedReader
  - It is used to read text from a character-input stream, buffering characters to provide efficient reading of characters, arrays, and lines.
  - It can read a line of text at a time using the readLine() method.

- FileInputStream
  - It is used to read data from a file in the form of bytes.
  - It is suitable for reading binary data like images, audio files, etc.
