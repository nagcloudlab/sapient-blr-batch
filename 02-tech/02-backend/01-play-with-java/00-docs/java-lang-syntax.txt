-----------------------------------------
3. Package Declaration
-----------------------------------------

why do we need package declaration?

- To avoid type name conflicts 
- To control access to types
- To make searching/locating and usage of types easier

syntax: 

package package_name;

recommended package naming:
-------------------------------------

package domain.company_name.project_name.module_name;
package org.npci.upi.account;

Quick introduction Object Oriented Programming (OOP) concepts
---------------------------------------------------------------

what is object?

 -> data|info|properties|attributes => State
 -> behavior|actions|functions|methods => Behavior
 -> address|location|reference => Identity

 object => sbi

 what is class?

 -> blueprint|template for creating objects
 -> defines the state and behavior that the objects of the class will have


OO concepts
---------------

1. front-end | interface | abstraction
2. back-end | implementation | encapsulation
3. inheritance | reusability
4. polymorphism | flexibility | extensibility

6. Variables => datatypes
-----------------------------------------
2 types of variables

1. value type variables (primitive types) 
    -> boolean, byte, char, short, int, long, float, double
2. reference type variables (user defined types)
    -> interface, class, enum, annotation

class Employee{
    static String tnrName; // class variable
    String name; // instance variable
    void m(){
         int v; // local variable
    }
}


syntax:

 _______       ___________ type varName=[value/object's reference];
 [public]       [static  ]
 [      ]       [final   ]
 [protected]    [transient]
 [private ]     [volatile]

 ---------local variables----------------
 Nil             [final ]



 ---------------------------
 7. constructors
-----------------------------

in java, object creation is a two-step process

step-1: dynamically allocate memory JVM's heap memory. => new keyword
step-2: initialize the memory with object's data => constructor

object creation syntax:

Type refVar = new Type(constructor-args);

syntax of constructor:

class ClassName{
    [public] [protected] [private] ClassName(constructor-args){
        // initialization code
    }
}

-----------------------------------------------------
Java Naming Conventions
-----------------------------------------------------

keywords: lowercase
package names: lowercase e.g org.npci.upi.account
Type Names : PascalCase e.g JavaProject, Employee, Gender
variable|method names: camelCase e.g empName, getEmpName(), setEmpName()
constants: UPPERCASE e.g MAX_VALUE, MIN_VALUE
