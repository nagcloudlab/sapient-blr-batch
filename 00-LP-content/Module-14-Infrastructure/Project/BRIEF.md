# Module 14: Infrastructure Fundamentals -- FoodExpress Infrastructure Review

## Sustain Context

The client escalated:

> "FoodExpress had two outages last month, our cloud bill is growing 15% month-over-month with no traffic increase, and the team does not understand our infrastructure well enough to troubleshoot effectively. Before we move to DevOps, we need everyone to understand infrastructure components, cloud vs on-prem trade-offs, resilience patterns, and cost management. Complete the exercises and pass the stage gate assessment to proceed."

---

## Tasks

| # | Type | Task | Deliverable |
|---|------|------|-------------|
| 1 | EXERCISE | Map FoodExpress components to infrastructure layers and service models | Completed component mapping table |
| 2 | EXERCISE | Cloud vs On-Prem decision matrix for 6 FoodExpress services | Recommendation table with justification |
| 3 | EXERCISE | Calculate system availability; design HA architecture | Calculations + architecture description |
| 4 | EXERCISE | Identify 5+ cost optimization opportunities from $15K bill | Savings table with estimates and timeline |
| 5 | EXERCISE | Analyze 2 production incidents (DB pool, cert expiry) | Root cause + preventive measures |
| 6 | ASSESSMENT | Stage Gate Exit Assessment (Modules 01-14) | MCQ + scenario + short answer score |

## Deliverables

- [ ] All 5 exercises completed with written answers
- [ ] Availability calculations shown with work
- [ ] Cost savings totaling at least $3,000/month identified
- [ ] Incident analysis with root causes and 3 preventive measures each
- [ ] Stage Gate Exit Assessment passed (60% minimum)
