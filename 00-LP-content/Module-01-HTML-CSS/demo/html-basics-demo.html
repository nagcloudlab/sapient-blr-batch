Source Code Comparison

WITHOUT Semantic Tags

<!-- Header -->
<div class="header">
  <h1>FoodExpress</h1>
  <div>Delicious food</div>
</div>

<!-- Navigation -->
<div class="nav">
  <a href="#">Home</a>
  <a href="#">Menu</a>
</div>

<!-- Content -->
<div class="content">
  <div class="section">
    <div class="restaurant">
      <h3>Biryani Palace</h3>
      <img src="biryani.jpg">
      <div><b>4.5/5</b></div>
    </div>
  </div>

  <!-- Table -->
  <table>
    <tr>
      <td><b>Item</b></td>
      <td><b>Price</b></td>
    </tr>
    <tr>
      <td>Biryani</td>
      <td>Rs.250</td>
    </tr>
  </table>

  <!-- Text -->
  <div>
    <b>SALE!</b> <i>50% OFF</i>
    Code: <b>WELCOME50</b>
  </div>

  <!-- Form -->
  <div>
    <label>Name</label>
    <input type="text">
    <label>Email</label>
    <input type="text">
    <button>Submit</button>
  </div>
</div>

<!-- Footer -->
<div class="footer">
  <div>Copyright 2026</div>
</div>

WITH Semantic Tags

<!-- Header -->
<header>
  <h1>FoodExpress</h1>
  <p>Delicious food</p>
</header>

<!-- Navigation -->
<nav aria-label="Main navigation">
  <a href="#menu">Home</a>
  <a href="#menu">Menu</a>
</nav>

<!-- Content -->
<main>
  <section id="restaurants">
    <article>
      <h3>Biryani Palace</h3>
      <figure>
        <img src="biryani.jpg"
             alt="Biryani Palace restaurant">
        <figcaption>Since 2015</figcaption>
      </figure>
      <p><strong>4.5/5</strong></p>
    </article>
  </section>

  <!-- Table -->
  <table>
    <thead>
      <tr>
        <th scope="col">Item</th>
        <th scope="col">Price</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>Biryani</td>
        <td>Rs.250</td>
      </tr>
    </tbody>
  </table>

  <!-- Text -->
  <p>
    <strong>SALE!</strong>
    <mark>50% OFF</mark>
    Code: <code>WELCOME50</code>
  </p>

  <!-- Form -->
  <form action="/contact" method="POST">
    <label for="name">Name</label>
    <input type="text" id="name" required>
    <label for="email">Email</label>
    <input type="email" id="email" required>
    <button type="submit">Submit</button>
  </form>
</main>

<!-- Footer -->
<footer>
  <small>&copy; 2026</small>
  <address>support@foodexpress.com</address>
</footer>

Key Differences Summary

Element Without Semantic With Semantic Why It Matters
Page header<div class="header"><header>Screen readers identify page header
Navigation<div class="nav"><nav aria-label="...">Assistive tech can skip to nav
Main content<div class="content"><main>Only one per page, landmark role
Content blocks<div class="section"><section>Thematic grouping with outline
Standalone content<div><article>Independently distributable
Images<img> (no alt)<figure> + <figcaption> + altAccessibility and context
Emphasis<b> / <i><strong> / <em>Semantic meaning, not just visual
Highlight<b> with color<mark>Indicates relevance
Deleted/Added<s> / manual<del> / <ins>Document changes semantically
Code text<b><code>Identifies code fragments
Date/TimePlain text<time datetime="...">Machine-readable dates
Table headers<td> + <b><th scope="col"> in <thead>Screen readers announce headers
Form<div> (no action)<form action="..." method="...">Submittable, accessible
Input typestype="text" for alltype="email", "tel" + requiredMobile keyboards, validation
Label binding<label> (no for)<label for="id">Click label focuses input
Footer<div class="footer"><footer> + <address> + <small>Landmark role, contact semantics
Supplementary<div><aside>Related but not primary content
