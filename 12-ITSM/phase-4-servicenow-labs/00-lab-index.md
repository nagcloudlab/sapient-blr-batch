# ServiceNow Lab Guides -- Zero to Expertise

## How to Use These Labs

Each lab builds on the previous one. Complete them in order. All labs use a **free Personal Developer Instance (PDI)** from developer.servicenow.com.

### Difficulty Levels

| Level | Labs | Who It's For |
|---|---|---|
| **Beginner** | Lab 01-06 | First-time ServiceNow users |
| **Intermediate** | Lab 07-12 | Comfortable with navigation, ready for ITSM modules |
| **Advanced** | Lab 13-18 | Ready for automation, scripting, and customization |
| **Expert** | Lab 19-21 | Production-ready skills: APIs, deployment, testing |

## Prerequisites

- A computer with a modern web browser (Chrome recommended)
- Internet access
- A ServiceNow developer account (free -- created in Lab 01)
- Basic understanding of ITSM concepts (Phase 1-2 of this course)
