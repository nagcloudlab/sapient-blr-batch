# DevOps Capsule Project -- Project Brief
## Module 31 | Days 34-35

---

## Sustain Context

FoodExpress needs a complete DevOps pipeline built from scratch. The current process is manual: developers build locally, SCP JARs to servers, and restart services by hand. Your team will build an automated pipeline using Docker, Jenkins, Kubernetes, and Ansible.
