Principles
Quality mindset
Quality Principles
Simple rules freshers can apply on every sustain ticket.
  • Prevention over detection: stop FoodExpress bugs before users find them.
  • Shift left: test assumptions while changes are still cheap.
  • Everyone owns quality: developers, testers, product, and operations.
  • Every bug fix gets a test so the same defect cannot return silently.
  • Ask "how was this missed?" after each production issue.

Testing Fundamentals
Testing
Core idea
What Is Testing?
Testing gives evidence, not guarantees.
Can prove
Presence of bugs
If a FoodExpress refund test fails, you know that behavior is defective.
Cannot prove
Absence of bugs
If checkout tests pass, untested edge cases can still fail in production.
Definition
Testing reduces risk. It does not eliminate risk.
