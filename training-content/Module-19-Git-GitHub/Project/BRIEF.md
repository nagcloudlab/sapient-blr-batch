## Sustain Context

The FoodExpress Git repository has accumulated bad practices over time: poor .gitignore configuration, meaningless commit messages, inconsistent branch naming, and unresolved merge conflicts blocking feature delivery. As a sustain engineer, you need to clean up the repository and establish proper Git workflows for the team.
