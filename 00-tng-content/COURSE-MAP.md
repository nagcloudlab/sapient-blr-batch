## Assessment Checkpoints

| Type | Module | Day | Description |
|------|--------|-----|-------------|
| Capsule | M08 -- Java Capsule | Day 9 | Java fundamentals: OOP, collections, Spring Boot basics |
| Capsule | M11 -- NodeJS Capsule | Day 12 | Node.js: Express API, async patterns, middleware |
| Capsule | M17 -- Integration Capsule | Day 18 | Full-stack integration: frontend + backend + database |
| Capsule | M23 -- Platform Capsule | Day 24 | Process & tools: SDLC, DevOps, Git, Linux, Apache, Microservices |
| Capsule | M31 -- DevOps Capsule | Day 32 | Platform engineering: Docker, Jenkins, Kubernetes, Ansible |
| Stage Gate | M34 -- MidStage + ITSM | Days 35 -- 38 | Mid-programme evaluation covering M01 -- M33 + ITSM foundations |
| Stage Gate | M37 -- Final + GenAI | Days 43 -- 44 | Final evaluation: full programme + GenAI in sustain engineering |

**Capsule modules** are project-only days -- no new theory. Participants integrate prior learning into the FoodExpress incremental project.

**Stage gates** involve formal assessment: written test, code review, and trainer sign-off required to proceed.
