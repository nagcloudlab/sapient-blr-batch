CSS Box Model

Every HTML element is a box. The box model defines: Content + Padding + Border + Margin.

1. The Box Model - Visual

2. content-box vs border-box

This is the #1 CSS gotcha. With content-box (default), width does NOT include padding/border.

content-box (default - problematic)
.card {
  width: 300px;
  padding: 20px;
  border: 3px solid;
  /* Actual width = 300 + 40 + 6 = 346px! */
}

3. Margin Collapse

When two vertical margins touch, they COLLAPSE into one (the larger wins). This is a classic CSS surprise.

.restaurant-a { margin-bottom: 30px; }
.restaurant-b { margin-top: 30px; }

/* Expected gap: 60px */
/* Actual gap: 30px (collapsed!) */
Restaurant A
margin-bottom: 30px
Restaurant B
margin-top: 30px

Gap is 30px, not 60px - margins collapsed!

4. Shorthand Properties

/* Margin / Padding shorthand */
margin: 10px; /* all sides: 10px */
margin: 10px 20px; /* top/bottom: 10px, left/right: 20px */
margin: 10px 20px 30px; /* top: 10, left/right: 20, bottom: 30 */
margin: 10px 20px 30px 40px; /* top, right, bottom, left (clockwise) */

/* Border shorthand */
border: 2px solid #e84c3d; /* width style color */

/* Centering a block element */
margin: 0 auto; /* top/bottom: 0, left/right: auto = centered */

2. When to Use What?

LayoutDimensionBest ForFoodExpress Example
Flexbox 1D (row OR column) Navigation bars, card rows, centering, form layouts Navbar, order tracker, restaurant card row
Grid 2D (rows AND columns) Full page layouts, dashboards, menu grids, complex layouts Page layout, menu grid, admin dashboard
Float — Wrapping text around images (that's it!) Restaurant description wrapping around a logo
Position — Overlays, badges, fixed elements, sticky headers Discount badge, sticky cart, floating button
Quick Rule of Thumb:
Laying out items in a line (row or column)? Use Flexbox.
Laying out items in a grid (rows and columns together)? Use Grid.
Need something to float over other content? Use Position.
Wrapping text around an image? That's the one place Float is still useful.
